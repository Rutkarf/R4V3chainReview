**SAWT** = programme radio de la Nation. Il emporte des **tags** (empreintes / preuves) issus de l’état et des transactions **CAN0PY** hors du seul web — vers le sol (**LORA**), la voûte (**iono**), et un jour l’echo lunaire (**Moon Bounce / EME**).

| Médium | Portée | Message pédagogique |
|:-------|:-------|:--------------------|
| ◆ **LORA** | Proche / mesh | *LORA touche le proche.* |
| ◆ **Ionosphère** | Voûte | *L’iono ouvre le ciel.* |
| ◆ **Moon Bounce** | Aller-retour Lune | *La Lune compte — elle ne triche pas.* |

```

       ├─ Tag LORA (sol)
       ├─ Tag ionosphérique (ciel)
```
